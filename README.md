# CodeQuest

AI-powered gamified DSA learning platform — React + FastAPI + PostgreSQL + Judge0 + Gemini.

Solve problems in Python, C++, or Java against a real judge, earn XP and badges, keep a daily streak, and get Gemini-generated progressive hints and failure reviews when you're stuck.

## Stack

| Layer | Tech |
| --- | --- |
| Frontend | React 19, Vite, Tailwind CSS v4, CodeMirror 6 (@uiw), React Router, Axios, Lucide |
| Backend | Python 3.11, FastAPI, SQLAlchemy 2, Alembic, Pydantic v2, PyJWT, passlib |
| Database | PostgreSQL 16 (Docker Compose) |
| Execution | Judge0 CE (self-hosted on `:2358`, RapidAPI-compatible) |
| AI Tutor | Google Gemini (`gemini-3.6-flash` by default) |
| Type | Chakra Petch / IBM Plex Sans / JetBrains Mono via @fontsource (self-hosted) |

## Features

- **Problem library** — 34 seeded problems across Array, String, Linked List, Stack, Queue, Tree, Graph, DP; always listed easy → medium → hard; topic filters, difficulty stamps, title search
- **Real judging** — Run (visible cases with input/expected/your-output diff) and Submit (all tests, runtime + memory per attempt) via Judge0 for Python, C++, Java
- **Parse-only starter code** — every language scaffold parses input and marks where your solution goes; no stub answers to delete (validated by `backend/scripts/check_starters.py`)
- **Gamification** — XP on first solve, daily streaks, 12 unlockable badges, dashboard campaign view with a topic "trail" progress map
- **Progressive hints** — three levels (Nudge → Approach → Sketch) generated by Gemini, cached per problem; viewing any hint forfeits first-solve XP
- **AI failure reviews** — verdict, bug type, explanation, and fix hint for failed submissions; cached per submission; hidden tests are never exposed to the model or UI

## Setup

### 1. Environment

```powershell
Copy-Item .env.example .env
```

Fill in:

- `GEMINI_API_KEY` — https://aistudio.google.com/apikey
- `JUDGE0_API_URL=http://localhost:2358` for the bundled/self-hosted judge (or point at RapidAPI and set key/host)

### 2. Database

```powershell
docker compose up -d
```

### 3. Backend

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

API docs: http://localhost:8000/docs

### 4. Frontend

```powershell
cd frontend
npm install
npm run dev
```

App: http://localhost:5173 (proxies `/api` to the backend)

## Backend scripts

Run from `backend/` with the venv active:

| Command | Purpose |
| --- | --- |
| `alembic upgrade head` | Apply migrations (from `backend/`) |
| `python scripts/migrate_005_ai.py` | One-off shim adding hint/AI tables (idempotent) |
| `python scripts/seed.py` | Seed/update the 34-problem library |
| `python scripts/verify_seeds.py` | Verify all 171 seed test cases compile and pass against reference solutions |
| `python scripts/check_starters.py` | Compile-check every starter block (Python locally, C++ via Judge0) |

## Tests

```powershell
cd backend
pytest -q
```

41 tests cover auth, problems, grading, gamification, and the AI tutor endpoints (Gemini and Judge0 are mocked; tests run against the local database).
